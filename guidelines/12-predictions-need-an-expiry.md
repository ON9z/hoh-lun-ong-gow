# 预测要带到期日：落盘 + 定时提醒 + 「不成立意味着什么」

判据：这条预测的**核对日**与**核对方式**（哪条命令/哪条查询）写下来了吗？
**不成立意味着什么**写下来了吗？

**⇒ 为什么**：**可证伪预测会过期，过期就再也查不出。**

**⇒ 三件一起做**：
① 写进落盘文件，含**核对日**与**核对方式**；
② 上**一次性定时提醒**（到期那天自动唤回）；
③ 提醒内容带上「**不成立意味着什么**」——
   ✗ 「看一眼结果」 ✓ 「不出现 ⇒ 说明那个修复没生效 ⇒ 回头查，**不要解释成"没有信号"**」。

**⇒ 更强的形态**：交付「**预期会失败**」的结果时，**必须附决策表**（什么现象=正常 / 什么现象=回归 / 告警后怎么补）。
> **没有这张表，下一个人会把"正确的失败"当 bug 回滚。**
